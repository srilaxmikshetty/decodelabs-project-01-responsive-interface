# DecodeLabs Project 01 — Responsive Frontend Interface

A framework-free responsive frontend built for the DecodeLabs Industrial Training Project 01 brief.

## Requirements covered
- Semantic HTML5 landmarks (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Mobile-first responsive CSS
- CSS Grid for macro layouts and Flexbox for components
- Fluid typography with `clamp()`
- Responsive navigation with basic JavaScript
- Dark/light theme toggle
- Accessible skip link, labels, focusable controls, ARIA state, and live status feedback
- Project checklist interaction
- No frontend framework or external JS dependency

## Run
Open `index.html` in a browser. For the best local development experience, serve the folder with any simple static server.

## Files
- `index.html` — semantic page structure
- `css/styles.css` — responsive visual system
- `js/app.js` — navigation, theme, checklist, and active-section logic
